# Concrete Analytics
This repository is the official page for the log viewer tool Concrete Analytics. Concrete Analytics mission statement is to collate WoW Forever log data in a way that makes it actionable for raiders and raid leaders in assessing player performance.

**This software is not affiliated with or endorsed by Activision Blizzard Inc.**

## Feature list
- One page design with simplicity at it's center
- Load any raid/dungeon log, even low level ones!
- View full raid, just trash or specific boss data
- View all raid members or show by class
- Select which casts to track
- Select which consumables to track
- Tracks deaths, damage done, DPS, attacks, casts, heals, damage taken, damage taken sources, hps, overhealing and healing targets by default

## Setup
- Download the latest versions .zip file
- Extract to desired location
- Click the concrete-analytics.exe file to run
***Important the .exe and .pck files have to be in the same directory***
